UV填充方式

UV空间比邻：仅在 2D UV 平面上进行外扩计算。直接抓取当前 UV 岛边界最外侧的像素颜色，沿着边界向外推（Push/Stretch）进行射线状延伸或膨胀填充。 3D空间比邻：结合 3D 模型的拓扑结构进行填充计算。当渲染到某条 UV 缝合线边界时，系统会去找在 3D 空间中与该缝合线无缝连接的“对面”那个面的像素颜色，并将其复制/混合填充到当前 UV 岛外的 Padding 区域中。

图层合成选项

  1. 基础/覆盖类 • Copy / Normal（直接覆盖） • 作用： 上层直接盖住下层（根据不透明度混合）。 • 场景： 贴上不透明的贴纸、花纹、材质遮罩（Mask）。
  2. 变暗/减法类（保留较暗/低值区域） • Multiply（正片叠底） • 算法： 像素值相乘（A x B）。白色（1）变透明，黑色（0）保留。 • 场景： 叠加环境光遮蔽（AO）、添加污垢、压暗局部颜色、合并黑色遮罩（Mask 与操作）。 • Subtract（减去） • 作用： 用下层减去上层的值。 • 场景： 雕刻凹坑、在高度图上扣除某些区域（例如在平地上挖出沟壑）。 • Min (Darken)（变暗/最小值） • 作用： 比较上下层，取更暗（数值更小）的像素。 • 场景： 限制高度图的最大值，确保叠加后不会超过某个高度 limit。
  3. 变亮/加法类（保留较亮/高值区域） • Screen（滤色） • 算法： 类似投影叠加，黑色（0）透明，白色（1）保留，效果比 Add 更柔和，不易爆白。 • 场景： 叠加灰尘、积雪、提亮 BaseColor、混合柔和的光照或高光细节。 • Add (Linear Dodge)（线性发光/加算） • 算法： 像素直接相加（）。 • 场景： 叠加高度图（Height Map）的突起细节（如在墙面上叠加凸起的砖纹或颗粒），制作自发光（Emissive）。 • Max (Lighten)（变亮/最大值） • 作用： 比较上下层，取更亮（数值更大）的像素。 • 场景： 合并两个不同形状的高度图（例如将凸起的螺丝放置在钢板上，保留最高点）。
  4. 对比/叠加类（中间调混合） • Overlay（叠加） • 算法： 暗部更暗（Multiply），亮部更亮（Screen），保留下层的明暗对比。 • 场景： 为灰度纹理快速上色、增加材质的表面对比度和质感细节。
  5. 法线与特殊通道类 • Overlay / Reoriented Normal（法线叠加/定向法线混合） • 作用： 在法线通道（Normal Map）中使用时，用于将细微的法线纹理（如布料纹理、皮肤毛孔）正确叠加到宏观的法线大结构上，而不会破坏法线贴图的方向向量。
